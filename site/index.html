The product promise

No hidden infrastructure decision

Explicit account service

Matrix.org is prominent, reviewed alternatives are visible, and another compatible service is always available.

Federated communities

Your account does not need to live on the same service as the community you join.

Honest limits

Operators, policies, registration paths, availability, and known free-use limits are shown before you choose.

Current release state

Developer preview, not a consumer beta

Public code signing and signed automatic updates are not yet provisioned. Unsigned artifacts must be treated as developer previews. Mesh will not call a Windows package production-ready until trusted signing, clean-device install, update, rollback, and external download checks pass on one release SHA.
