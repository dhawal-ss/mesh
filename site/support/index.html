Support and abuse routing

Send the issue to the operator who can act

Supported beta surface

  • Windows is the only candidate platform. It is still a developer preview until signed clean-device acceptance passes.
  • Voice is included in the signed draft candidate. It is still blocked from public-beta promotion until the complete two-device, network, TURN, and media-encryption acceptance campaign passes.
  • Automatic updates remain disabled. Do not bypass operating-system warnings or install an unsigned package as a consumer beta.
  • macOS and Linux are not advertised as supported. Their native invitation and assistive-technology campaigns have not run.

Mesh desktop app

For reproducible app bugs without sensitive data, open a GitHub issue. Include the version, operating system, expected result, and sanitized steps.

Account service

Registration, login policy, provider moderation, service limits, remote deactivation, and provider outages belong to the selected account-service operator. Use the terms, privacy, status, and support links shown by Mesh.

Community

Membership decisions, room rules, reporting, and a community-hosted service belong to that community's administrators. A community-hosted Mac mini may have no uptime SLA.

Reports and appeals

Mesh routes reports to the community or service operator that has authority to act. Appeals go to the operator whose decision is being challenged; Mesh cannot promise a universal appeal across independently operated services.

Crash diagnostics

Mesh does not upload crash diagnostics automatically. Remove account IDs, room IDs, invitation links, message content, recovery material, and local file paths before attaching diagnostics to a support request.

Security

Before sharing vulnerability details, check the security reporting status. Do not place exploit details or credentials in a public issue.
