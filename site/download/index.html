Developer previews only

The public release path is prepared, but trusted Windows signing and signed automatic updates are still release blockers.

Do not bypass Windows security warnings. Until a package is signed by a reviewed trusted certificate, use it only for controlled development testing.

Get the latest reviewed artifact

Releases will appear on the project's GitHub Releases page. Each reviewed release must include SHA-256 checksums and CycloneDX SBOMs. A missing checksum, unexpected signer, or failed signature means stop.

Verification

  1. Download the installer and SHA256SUMS.txt from the same release.
  2. Compare the local SHA-256 hash with the published value.
  3. For a consumer beta, verify a valid trusted Authenticode signature and timestamp.
  4. Confirm the version and channel before installing or rolling back.

A canonical latest-download redirect will be enabled only after a signed release exists and is verified from outside the development machine.
