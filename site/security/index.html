Security

Report vulnerabilities privately

Do not file a public issue containing exploit details, credentials, invitation capabilities, private room IDs, or user data.

Open a private security advisory

Include

  • the affected Mesh version and operating system;
  • reproduction steps with secrets and personal data removed;
  • the impact and whether the issue is actively exploited;
  • a safe way to coordinate follow-up.

Release trust

Reviewed releases provide checksums and SBOMs. A consumer Windows beta additionally requires a trusted Authenticode signature and timestamp. The Tauri updater requires a separate signing key and must reject invalid manifests and signatures.

Provider incidents

Report an incident in an independently operated account service to that operator. A community-hosted service's abuse and incident contact belongs to its community owner.
